# Изображения каталога

`npm run images:prepare` создаёт WebP-превью существующих фотографий на компьютере разработчика. Источники берутся из публичных API сайта; оригиналы и база не изменяются. Готовые файлы находятся в `public/catalog-previews`, соответствия — в `lib/catalog-image-previews.json`. Оба каталога данных нужно включать в коммит и выпускать вместе.

Ширины превью — до 384, 768 и 1280 пикселей. Имена включают хеш содержимого и настроек преобразования: файлы можно кэшировать на год. Браузер выбирает подходящий размер через `srcset`. Изображения, которых нет в манифесте (например, новые загрузки из админки), продолжают работать через штатный оптимизатор Next.js. Если готовое превью недоступно, компонент также возвращается к исходному изображению через Next.js.

Повторный запуск подготавливает только недостающие превью. `npm run images:prepare -- --refresh` обновляет все источники, в том числе если файл был заменён по прежнему URL. При ошибке загрузки источник остаётся на штатном механизме Next.js, ошибка выводится в отчёте скрипта.

На VPS с 1 ГБ RAM сборку и массовое преобразование не запускать. Собирать в локальной Linux-среде с той же версией Node.js и lock-файлом; на VPS передавать готовую `.next`, а исходники и `public/catalog-previews` обновлять через Git. При замене `.next` сохранять её `cache/images` для новых фотографий, ещё не включённых в манифест.
